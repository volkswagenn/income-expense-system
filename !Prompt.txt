การบันทึก log
ไฟล์ Log *บันทึก log ตามหัวข้อต่อไปนี้
	- ข้อมูลพื้นฐานของกิจกรรม

		- วันที่และเวลา (Timestamp) → เพื่อระบุว่าเกิดขึ้นเมื่อไหร่

		- ประเภทกิจกรรม → เช่น เพิ่มรายรับ, แก้ไขรายจ่าย, ลบข้อมูล, เข้าสู่ระบบ
	- รายละเอียดการเปลี่ยนแปลง

		- ค่าเดิม (Old Value) → เช่น รายจ่ายเดิม 500 บาท

		- ค่าที่แก้ไขใหม่ (New Value) → เช่น เปลี่ยนเป็น 700 บาท

		- หมายเหตุ/เหตุผลในการแก้ไข → เพื่ออธิบายว่าทำไมถึงเปลี่ยน
	- สถานะการทำงาน

		- ผลลัพธ์ → สำเร็จ หรือ ล้มเหลว

		- Error Message (ถ้ามี) → เช่น บันทึกไม่สำเร็จเพราะไฟล์เสียหาย

		- ข้อมูลระบบเพิ่มเติม (ถ้าต้องการความปลอดภัยสูง)

		- IP Address / Device → เพื่อระบุว่าใช้งานจากที่ไหน

		- Session ID → สำหรับตรวจสอบการใช้งานต่อเนื่อง
