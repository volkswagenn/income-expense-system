# โลโก้ธนาคาร

ไฟล์ SVG ในโฟลเดอร์นี้มาจาก **omise/banks-logo**

- ที่มา: https://github.com/omise/banks-logo
- สัญญาอนุญาตของชุดไฟล์: MIT License

โลโก้แต่ละอันยังคงเป็นเครื่องหมายการค้าของธนาคารเจ้าของ
ในแอปนี้ใช้เพื่อ **บ่งชี้ว่าบัญชีนั้นเป็นของธนาคารใด** เท่านั้น
ไม่ได้สื่อว่าธนาคารเป็นผู้พัฒนา สนับสนุน หรือรับรองแอปนี้

## เพิ่ม / เปลี่ยนโลโก้เอง

ตั้งชื่อไฟล์ตาม `code` ที่กำหนดไว้ใน `src/lib/banks.js` เช่น `kbank.svg`
ถ้าไฟล์หายหรือโหลดไม่ขึ้น ระบบจะแสดงตราสีประจำธนาคารพร้อมรหัสย่อแทนอัตโนมัติ
